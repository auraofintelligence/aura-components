A large, single-page browser prototype that collects several Aura of Intelligence interface experiments around a seven-shell, 12 × 24 torus field.

## Public page

[Explore the live component prototype](https://auraofintelligence.github.io/aura-components/).

## Included prototype areas

- Avatar Builder
- Timeline Mastery
- Memory Palace
- Social Media Intelligence
- Algorithm Marketplace and Tuning
- Intelligent File Storage
- IoT Omni-GUI Ecosystem

The page combines Three.js scenes, forms, timelines, synthetic examples and interactive panels in one HTML file. Some state can be saved in the current browser with `localStorage`; uploaded files are read by browser code. A location control may ask for browser geolocation permission when used.

## Open it locally

Open `index.html` in a modern browser. An internet connection is required for Three.js, Tailwind CSS and externally hosted fonts. There is no package install or build step.

## Status and privacy boundary

This is a component playground, not a finished Aura application. Demonstration buttons, device panels, scans, analytics, markets and storage views do not prove that production services, encryption, identity, health analysis, social-network access or IoT connections exist.

Treat any entered or imported information as local prototype data. Review browser permissions before using location. Do not enter sensitive personal, health, account or identity information into an experimental public page.
